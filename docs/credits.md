# Historical design assets

The revival carries forward the images, avatars and typefaces distributed with the [PHP edition](https://github.com/Moncada25/Bookverse/tree/ce5734c/vistas). The historical repository does not record the individual image creators or redistribution terms. The Bookverse MIT grant covers its own code and original sample texts.

| Asset | Upstream |
| --- | --- |
| Bootstrap 3.3.7 styles and bundled Glyphicons | [Bootstrap](https://github.com/twbs/bootstrap/tree/v3.3.7) |
| Bootstrap Material Design styles | [Bootstrap Material Design](https://github.com/FezVrasta/bootstrap-material-design) |
| Roboto Condensed, regular and light | [Google Fonts Roboto](https://github.com/googlefonts/roboto) |
| Material Design Iconic Font 2.2.0 | [Material Design Iconic Font licenses](https://zavoloklom.github.io/material-design-iconic-font/license.html) |

The demonstration PDFs *El cielo a simple vista* and *Cómo funciona un algoritmo* were written for this edition.
